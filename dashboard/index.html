How the ranking works

Every protocol in the snapshot that records no token is scored. The model never uses a hardcoded list of names: peer multiples are calibrated from the snapshot itself. Every tokenised protocol's market-cap/TVL ratio is winsorised to the snapshot's own 5–95% band, and each protocol is priced against a size-weighted median of its category's peers — peers within 8× of its own TVL count fully, the rest at 0.35 — shrunk toward the snapshot-wide multiple () so thin categories cannot blow up.

Implied FDV is a geometric blend, 65/35: the peer model — TVL × peer multiple × momentum (7-day TVL change, clamped, worth ×0.80–×1.15) × age (longer tokenless-and-large is worth up to ×1.25) × a size decay for very large TVL — and a fundamentals model with no category term, TVL × the snapshot-wide multiple × momentum × age. Implied value = implied FDV × 7.5% assumed airdrop share × P(launch), a smooth curve in TVL adjusted for tokenless age, the category's tokenisation rate, momentum and chain breadth.
